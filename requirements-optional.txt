# PDF to Excel Converter – Optional extraction engines
#
#   pip install -r requirements-optional.txt
#
# NOT required. These are fallback table engines, tried only when pdfplumber
# finds no tables on a page. Each depends on system software that pip cannot
# install, which is why they are kept out of requirements.txt - a failure here
# must not block a working install of the main tool.
#
# The tool checks at import whether each is available and skips it if not.
# Run `python pdf_to_excel.py --check-deps` to see the current status.

# ── Camelot – lattice/stream table detection ──────────────────────────────────
# Best on tables with visible ruling lines. Requires Ghostscript:
#   Windows : https://www.ghostscript.com/releases/gsdnld.html
#   macOS   : brew install ghostscript
#   Linux   : sudo apt-get install ghostscript
camelot-py[cv]>=0.11.0

# ── Tabula – Java-based extractor ─────────────────────────────────────────────
# Last-resort fallback; slower, but catches tables the others miss.
# Requires Java 8+ on PATH: https://www.java.com/en/download/
tabula-py>=2.9.0
